## 1. 静改方法

### 1.1 解包与回封

1. 把 `USRDIR\COMMONDATA\MTDATA\RPW_DATA.CPK` 拖入 `cpk_unpack0.77`，得到解包后的目录和 `00000.bin` —— 这个就是静改机体、人物、武器等数据的文件。
2. 修改文件后，用 `CRI Packed File Maker` 点一下文件夹的小图标，选择刚才解包得到的目录，列表里会看到该目录下的文件；然后点 `Build CPK file` → `Start to Build`，得到新的 `RPW_DATA.CPK`。

### 1.2 旧替换方法（需安装数据）

3. 把 `RPW_DATA.CPK` 替换主机的同名文件。注意：
   - **未打过 1.0X 补丁** → 替换 `GAMES` 目录的文件；
   - **已打 1.0X 补丁** → 替换 `game` 目录的文件。
4. 在 XMB 界面先删除安装数据，再进入游戏重装数据，修改内容才会生效。

### 1.3 新替换方法（不需安装数据，推荐反复测试时用）

3. 下载 `TrueAncestor PKG Creator v1.01` 和天狱篇的 1.0X 补丁（1.01、1.02 什么版本都可以），把补丁的 pkg 文件放到工具的 `pkg` 目录，选 `3.Extract PKG via PkgView`，完成后会把 pkg 的文件全部导出到游戏编号的文件夹。**这步只需导出一次，下次修改不用再重新导出。**
4. 把第 1.1 步修改后得到的 `RPW_DATA.CPK` 覆盖到上一步 pkg 目录下的 `BLJS10299\USRDIR\COMMONDATA\MTDATA` 同名文件；**如果修改过战场，就复制 `STGZ3OF2.SDAT` 到 `BLJS10299\USRDIR\DATA\STAGE`**。然后打开 `TrueAncestor PKG Creator v1.01`：

   1. 选 `1.Create PKG`
   2. 再选 `3.Disc Game Patch`
   3. 输入界面上 BLJS10299 对应的编号（一般只有这个目录，编号就是 1）
   4. 下一步 ContentID 输入除 A 以外的其他键，回车
   5. 版本输入 `01.01`，回车，再随便点一个键，后面会自动打包新的 PKG
   6. 生成 `JP9000-BLJS10299_00-DISCGAMEPATCH000.pkg` 后，把文件安装到主机

   这样就不需要每次修改都花 5 分钟重新安装数据。**需要多次测试修改数据时，建议封包 pkg 前先把 pkg 目录的 `USRDIR\DATA\AIDDATA` 删掉** —— 这个文件不需修改但占 20 多 M，去掉它安装 PKG 会更快。

### 1.4 测试技巧

> 由于连狱篇不需要安装数据，修改后也无需重装数据，所以建议用连狱篇测试修改的字节内容，再套用到天狱，这样就不用每次测试修改都要反复安装了。

## 2. 存档配合与已知问题（原帖 2021-12-05 18:27 补充楼）

**操作步骤**

1. `RPW_DATA.CPK` 放到游戏目录，例如 `BLJS10299-\PS3_GAME\USRDIR\COMMONDATA\MTDATA`；**替换前记得备份原文件**。
2. 存档 `npjb00692-stg-005` 连同文件夹一起复制到模拟器 `\dev_hdd0\home\00000001\savedata` 目录下；提示覆盖时记得备份源文件。
3. 删除游戏已安装到 `game` 目录下的数据，点击游戏开始，等待写入数据完毕，读取 2 号记录。

**不替换静态文件的后果**（原帖原话）

> 如不替换 rpwdata 文件，也可在编成界面看到 boss 和 boss 机，但无法保存 boss 经验，pp 等数据，而且每关会重置为 1 级。机体也无法保留改造数据。
